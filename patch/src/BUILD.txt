BUILD / REPRODUCIBILITY

PharaohHD.c is the same process-local adapter used in the local Full HD fix.
Compiler used: TinyCC 0.9.27, Windows x86 distribution.
https://bellard.org/tcc/
From the package root, with tcc.exe on PATH:
  tcc -shared src\PharaohHD.c -o PharaohHD.dll -luser32 -lgdi32
Expected SHA256:
638b593db81ddf0a73ccc2a05913c5bd621baa628836f77a200d29477e8a8fff
This release does not bundle the compiler or any of its distribution files.

IsoReader.cs is compiled in memory by Windows PowerShell's Add-Type.
It reads ISO 9660 primary directory entries without mounting the image.
The ZIP reader extracts only the single ISO entry to a fixed temporary name.
No program from the downloaded game archive is executed during installation.

patch.json stores 13 overwrite records (542 bytes total), the expected
executable length and hashes, and the required original asset hashes.
Install.ps1 creates a copy of the original executable, applies the records,
and verifies the resulting SHA256 before committing the new directory.
The appended compatibility stub contains initialization bytes generated by
the original PINSTALL.DLL GetSaveVector routine; no user registration key
or author-specific save/configuration data is included.

The DLL intercepts imports only in this exact 32-bit game executable.
It is not a general-purpose system DLL and must not be installed into Windows.
Debug logging is off by default; [Display] Debug=1 enables a local diagnostic
log containing window events and key codes. Leave it disabled for normal play.
